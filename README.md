#  AI Music Discovery 1.0

A personalized virtual DJ console developed in Python for Stanford's **Code in Place** course. This application integrates with an AI language model to recommend songs based on the user's mood, preferred genre, and specific topics.

##  Features
- **Smart Music Discovery:** Generates real-time song recommendations using AI.
- **Dynamic Retry System:** If you don't like a recommendation, the AI learns from the previous attempt and suggests a completely different song.
- **Personal Library:** Save your favorite recommendations or manually add songs to your custom playlist.

##  Technologies Used
- **Python 3**
- **OpenAI API** (via Code in Place `ai` module)
